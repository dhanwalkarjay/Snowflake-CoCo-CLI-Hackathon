### 3. `03_signal_evidence_finding.md` — Signal → Evidence → Finding Workflow
- **Signal layer**: Raw detections from rule engines or ML scoring (e.g., "TX > 10 000 in 24h", "Velocity spike", "Watchlist hit"). Written to `RISK.SIGNALS`.
- **Evidence layer**: Corroboration logic — signals grouped by entity + time window, enriched with context (peer-group deviation, network hops). Written to `RISK.EVIDENCE`.
- **Finding layer**: Adjudication — evidence clusters scored, thresholded, and classified (True Positive / False Positive / Escalate). Produces `RISK.FINDINGS` → auto-generates `RISK.ALERTS` → optionally opens `RISK.CASES`.
- Dynamic Table DAG: RAW → CORE (cleanse) → RISK.SIGNALS (detect) → RISK.EVIDENCE (correlate) → RISK.FINDINGS (adjudicate) → RISK.ALERTS
- Mermaid flow diagram of the full pipeline
