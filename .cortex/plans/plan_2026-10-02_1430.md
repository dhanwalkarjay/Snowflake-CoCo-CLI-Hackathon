**Explored:** Customer PII columns (FULL_NAME, PAN_NUMBER, AADHAAR_HASH, PHONE, EMAIL in RAW.CUSTOMERS; FULL_NAME only in CORE.DIM_CUSTOMERS), device columns (DEVICE_ID, IP_ADDRESS in RAW.TRANSACTIONS/CORE.FACT_TRANSACTIONS), 20 cities evenly distributed (250 customers each), all 3 procedures already EXECUTE AS CALLER, AUDIT_LOG table exists, no existing masking/RAP policies.

## Implementation Steps

### Step 1 — Create 3 roles + mapping table

```sql
CREATE ROLE FRAUD_ANALYST;
CREATE ROLE COMPLIANCE_OFFICER;
CREATE ROLE AUDITOR;
```

Grant hierarchy: each role → SENTINEL_WH usage, SENTINEL_DB usage, schema usage.

| Role | Can read | Can write | Special |
|---|---|---|---|
| FRAUD_ANALYST | RAW, CORE, RISK (alerts/rules), APP procs | Nothing | Row-filtered by city |
| COMPLIANCE_OFFICER | Everything FRAUD_ANALYST can + unmasked PII | RISK.FINDINGS, AUDIT.AUDIT_LOG | Sees all cities, all PII |
| AUDITOR | AUDIT.AUDIT_LOG, RISK.FINDINGS, RISK.ALERTS (read-only) | Nothing | Read-only audit trail |

Mapping table `RISK.ANALYST_CITY_ASSIGNMENTS` — maps USERNAME→CITY. Seed with demo data: JAYDHANWALKAR gets Mumbai+Delhi (subset).

### Step 2 — Masking policies (2 policies)

`APP.MASK_PII_STRING(val VARCHAR)` — returns `'***MASKED***'` unless `CURRENT_ROLE() IN ('COMPLIANCE_OFFICER','ACCOUNTADMIN')`.

Apply to: RAW.CUSTOMERS (FULL_NAME, PAN_NUMBER, AADHAAR_HASH, PHONE, EMAIL), CORE.DIM_CUSTOMERS (FULL_NAME), RAW.TRANSACTIONS (DEVICE_ID, IP_ADDRESS), CORE.FACT_TRANSACTIONS (DEVICE_ID, IP_ADDRESS).

### Step 3 — Row access policy

`APP.RAP_CITY_FILTER(city_val VARCHAR)` — returns TRUE if:
- `CURRENT_ROLE() IN ('COMPLIANCE_OFFICER','AUDITOR','ACCOUNTADMIN')` (full access), OR
- `CURRENT_ROLE() = 'FRAUD_ANALYST'` AND city is in the analyst's assigned cities from the mapping table

Apply to RAW.CUSTOMERS.CITY and CORE.DIM_CUSTOMERS.CITY.

### Step 4 — Audited agent wrapper procedure

Create `APP.AGENT_CHAT(question VARCHAR)` that:
1. Calls `SNOWFLAKE.CORTEX.DATA_AGENT_RUN(...)` 
2. INSERTs to AUDIT_LOG: user, role, question, tools used (parsed from response), timestamp
3. Returns the agent response

Update Streamlit Copilot page to call `AGENT_CHAT` instead of `DATA_AGENT_RUN` directly.

### Step 5 — Ensure procedures run as caller

All 3 procedures (GET_ACCOUNT_EVIDENCE, GENERATE_REPORT, LOG_FINDING) are already EXECUTE AS CALLER — masking and RAP policies apply automatically to the calling user's role.

### Step 6 — Grant roles to current user + demo

```sql
GRANT ROLE FRAUD_ANALYST TO USER JAYDHANWALKAR;
GRANT ROLE COMPLIANCE_OFFICER TO USER JAYDHANWALKAR;
GRANT ROLE AUDITOR TO USER JAYDHANWALKAR;
```

Demo query: `SELECT FULL_NAME, PAN_NUMBER, CITY FROM RAW.CUSTOMERS LIMIT 5` under each role — shows masked vs unmasked and city-filtered vs full.
