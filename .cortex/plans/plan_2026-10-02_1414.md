### 2. Write `streamlit_app.py` (home/nav)

Minimal: sets page config, sidebar title, shows welcome text. Multi-page via `pages/` directory convention.

### 3. Write each page

**Page 1 — Copilot:**
- `st.chat_input` + `st.chat_message` for chat UX
- Calls `SNOWFLAKE.CORTEX.DATA_AGENT_RUN(...)` via `session.sql()`
- Parses response JSON → extracts `content` array
- Shows answer text, expanders for tool_use entries (SQL, policy citations)
- Uses `st.session_state` for chat history

**Page 2 — Alert Queue:**
- 3 sidebar filters: rule (multiselect), severity (multiselect), status (selectbox)
- `SELECT ... FROM RISK.ALERTS JOIN RISK.RULES` with WHERE clause from filters
- `st.dataframe` with column config
- "Investigate" button per row → writes alert_id to `st.session_state`, switches to Case View

**Page 3 — Case View:**
- Reads `st.session_state.selected_alert_id` (or text input fallback)
- Calls `GET_ACCOUNT_EVIDENCE` via SQL, shows account profile
- Transaction timeline as `st.dataframe` sorted by date
- Rule hits + policy citation in expander
- "Generate Report" button → `CALL GENERATE_REPORT(?)` → displays report JSON formatted
- "Approve & Log Finding" button → `CALL LOG_FINDING(...)` → success toast

**Page 4 — Dashboard:**
- 5 KPI cards in `st.columns`: total alerts, critical alerts, open cases, NPA ratio, min LCR
- Bar chart: alerts by type (from RISK.ALERTS GROUP BY ALERT_TYPE)
- Precision/recall table: joins RISK.ALERTS with RAW.FRAUD_TRUTH
- All queries are simple aggregations — light on SENTINEL_WH

**Page 5 — Audit:**
- Latest 50 rows from `AUDIT.AUDIT_LOG` as dataframe
- Latest 50 rows from `RISK.FINDINGS` as dataframe
