# Sentinel — Data Model

> Banking / NBFC fraud, AML & regulatory-reporting copilot on Snowflake.
> All objects live in **SENTINEL_DB** across six schemas.

---

## Schema Map

| Schema | Purpose |
|--------|---------|
| `RAW` | Ingested source-of-record tables (append-only) |
| `CORE` | Cleansed & enriched dimensional / fact tables (dynamic tables) |
| `RISK` | Signal → Evidence → Finding pipeline, alerts, cases, SARs |
| `DOCS` | Regulation & policy corpus for Cortex Search |
| `APP` | Semantic view, Cortex Agent, search service definitions |
| `AUDIT` | Immutable audit log and model-decision ledger |

## 2 — CORE Schema (Dynamic Tables)

### CORE.DIM_CUSTOMERS

```sql
CREATE OR REPLACE DYNAMIC TABLE SENTINEL_DB.CORE.DIM_CUSTOMERS
    TARGET_LAG = '10 minutes'
    WAREHOUSE  = SENTINEL_WH
AS
SELECT
    c.CUSTOMER_ID,
    c.CUSTOMER_TYPE,
    c.FULL_NAME,
    c.DATE_OF_BIRTH,
    c.NATIONALITY,
    c.CITY,
    c.STATE,
    c.COUNTRY,
    c.KYC_STATUS,
    c.KYC_VERIFIED_AT,
    c.RISK_RATING,
    c.PEP_FLAG,
    c.ONBOARDED_AT,
    c.UPDATED_AT,
    DATEDIFF('day', c.ONBOARDED_AT, CURRENT_TIMESTAMP()) AS TENURE_DAYS,
    CASE
        WHEN c.KYC_STATUS = 'EXPIRED' THEN TRUE
        WHEN c.KYC_VERIFIED_AT < DATEADD('year', -2, CURRENT_TIMESTAMP()) THEN TRUE
        ELSE FALSE
    END AS KYC_OVERDUE_FLAG
FROM SENTINEL_DB.RAW.CUSTOMERS c;
```

### CORE.FACT_TRANSACTIONS

```sql
CREATE OR REPLACE DYNAMIC TABLE SENTINEL_DB.CORE.FACT_TRANSACTIONS
    TARGET_LAG = '5 minutes'
    WAREHOUSE  = SENTINEL_WH
AS
SELECT
    t.TXN_ID,
    t.ACCOUNT_ID,
    a.CUSTOMER_ID,
    t.TXN_TYPE,
    t.TXN_METHOD,
    t.AMOUNT,
    t.CURRENCY,
    t.COUNTERPARTY_NAME,
    t.COUNTERPARTY_ACCT,
    t.COUNTERPARTY_COUNTRY,
    t.REMITTANCE_INFO,
    t.CHANNEL,
    t.DEVICE_ID,
    t.IP_ADDRESS,
    t.GEO_LATITUDE,
    t.GEO_LONGITUDE,
    t.TXN_TIMESTAMP,
    t.TXN_TIMESTAMP::DATE                   AS TXN_DATE,
    t.STATUS,
    -- cross-border flag
    CASE WHEN t.COUNTERPARTY_COUNTRY IS NOT NULL
          AND t.COUNTERPARTY_COUNTRY <> 'IND'
         THEN TRUE ELSE FALSE END           AS IS_CROSS_BORDER,
    -- high-value flag (RBI threshold ₹10 lakh)
    CASE WHEN t.AMOUNT >= 1000000 THEN TRUE ELSE FALSE END AS IS_HIGH_VALUE,
    -- cash flag (CTR threshold ₹10 lakh)
    CASE WHEN t.TXN_METHOD = 'CASH' AND t.AMOUNT >= 1000000 THEN TRUE ELSE FALSE END AS IS_CTR_REPORTABLE
FROM SENTINEL_DB.RAW.TRANSACTIONS t
JOIN SENTINEL_DB.RAW.ACCOUNTS a ON t.ACCOUNT_ID = a.ACCOUNT_ID;
```

### CORE.FACT_LOANS

```sql
CREATE OR REPLACE DYNAMIC TABLE SENTINEL_DB.CORE.FACT_LOANS
    TARGET_LAG = '30 minutes'
    WAREHOUSE  = SENTINEL_WH
AS
SELECT
    l.LOAN_ID,
    l.CUSTOMER_ID,
    l.ACCOUNT_ID,
    l.LOAN_TYPE,
    l.PRINCIPAL,
    l.INTEREST_RATE,
    l.TENURE_MONTHS,
    l.EMI_AMOUNT,
    l.DISBURSED_AT,
    l.MATURITY_DATE,
    l.OUTSTANDING_BALANCE,
    l.DPD,
    l.NPA_FLAG,
    l.STATUS,
    -- RBI NPA classification
    CASE
        WHEN l.DPD > 90  THEN 'NPA_SUBSTANDARD'
        WHEN l.DPD > 180 THEN 'NPA_DOUBTFUL'
        WHEN l.DPD > 365 THEN 'NPA_LOSS'
        WHEN l.DPD > 0   THEN 'SMA'           -- Special Mention Account
        ELSE 'STANDARD'
    END AS ASSET_CLASSIFICATION,
    CASE
        WHEN l.DPD BETWEEN 1  AND 30  THEN 'SMA-0'
        WHEN l.DPD BETWEEN 31 AND 60  THEN 'SMA-1'
        WHEN l.DPD BETWEEN 61 AND 90  THEN 'SMA-2'
        ELSE NULL
    END AS SMA_CATEGORY
FROM SENTINEL_DB.RAW.LOANS l;
```
